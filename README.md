# ChessMind 1.0

Русскоязычное PWA для локального разбора завершённых шахматных партий. Stockfish 19 WASM работает на устройстве, партии и результаты хранятся в IndexedDB. Доступ к Chess.com и Lichess нужен только при обновлении истории.

- `npm ci` устанавливает зависимости.
- `npm run dev` запускает разработку.
- `npm run build` создаёт статическую сборку в `dist`.
- `npm run preview` запускает собранное приложение с Service Worker и заголовками для многопоточного WASM.

Конфигурация Vercel находится в `vercel.json`. Сборка использует Node.js 22.12+ или 24, регистрацию и секреты приложения настраивать не нужно. Офлайн-режим готов после установки Service Worker. На iPhone в Safari выберите «Поделиться» → «На экран Домой» → «Добавить».

Формулы, параметры движка и ограничения рейтингового ориентира описаны в разделе «Методология». Исходники и лицензии ресурсов перечислены в [NOTICE](public/legal/NOTICE.txt).
