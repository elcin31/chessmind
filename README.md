# ChessMind 1.0

ChessMind — русскоязычный офлайн-ассистент для шахматных тренировок на Android. Приложение включает официальный Stockfish 17.1 и работает без аккаунта, подписки и сетевых разрешений.

## Установка

1. Возьмите `ChessMind-1.0.apk` из комплекта ChessMind 1.0. Архив `ChessMind-1.0-APK.zip` содержит тот же APK.
2. Откройте файл на устройстве с Android 10 или новее. Если Android запросит разрешение на установку из этого источника, выдайте его приложению, из которого открыли файл.
3. После установки запустите ChessMind. Доступны ARM64 и x86_64.

[Исходники версии ChessMind 1.0](https://github.com/elcin31/chessmind/releases/tag/v1.0.0)

При установке через USB используйте:

```sh
adb install ChessMind-1.0.apk
```

## Режимы

| Режим | Возможности |
| --- | --- |
| Ассистент | Партия с ботом на доске ChessMind, распознавание экрана, лучший ход, оценка и ещё до двух вариантов в плавающем окне |
| Тренировки | Игра с ботом за белых или чёрных, три уровня сложности и история ходов |
| Автопилот | Stockfish играет за обе стороны на встроенной доске. Доступны пауза и сохранение партии |
| Анализ | Вставка одной партии PGN или позиции FEN, просмотр отдельных полуходов, варианты, оценка и копирование FEN |
| Ручная расстановка | Редактор фигур, стороны хода, рокировки и клетки взятия на проходе с проверкой итогового FEN |

Завершённые локальные партии сохраняются автоматически. Текущую партию или импортированную позицию можно сохранить кнопкой «Сохранить». История хранится на устройстве и содержит до 40 записей.

## Экранный ассистент

1. Откройте «Ассистент», выберите цвет и сложность и нажмите «Открыть доску ассистента».
2. Нажмите «Включить захват экрана». В системных настройках разрешите ChessMind отображаться поверх других приложений. На Xiaomi пункт может называться «Всплывающие окна» или «Показывать поверх других приложений».
3. В диалоге Android 14 или новее выберите отдельное приложение и укажите ChessMind. На более ранних версиях Android системный диалог может предлагать только запись всего экрана.
4. Перетащите окно за заголовок, измените размер за нижний угол, сверните кнопкой «−» или завершите захват кнопкой «×». Прозрачность и смещение области распознавания доступны под доской.

Распознавание поддерживает три встроенные палитры, два набора фигур и обе ориентации. ChessMind проверяет метки текущей тренировочной сессии, расположение фигур и легальность перехода между кадрами. FEN формируется с учётом истории партии. При потере уверенности, смене приложения или отзыве разрешения рекомендации скрываются или заменяются статусом паузы. Экранные кадры обрабатываются в памяти и удаляются сразу после обработки. Сторонние доски и сервисы экранного ассистента не поддерживаются.

## Сборка

Нужны Linux x86_64, JDK 17 или 21, Android SDK Platform 35, Build Tools 35.0.0, NDK 27.2.12479018, GNU Make, curl и sha256sum. Укажите путь к SDK в `ANDROID_HOME` или в `local.properties`.

```sh
sdkmanager 'platforms;android-35' 'build-tools;35.0.0' 'ndk;27.2.12479018' 'platform-tools'
./gradlew :app:testDebugUnitTest :app:assembleDebug
./gradlew :app:connectedDebugAndroidTest
./gradlew :app:assembleRelease
```

Сборка скачивает две официальные сети NNUE и проверяет их SHA-256. Для сборки с уже скачанными сетями задайте `STOCKFISH_NETWORK_DIR`. Полный исходный ZIP из комплекта ChessMind 1.0 содержит обе сети в `third_party/networks`. При сборке из этого архива можно задать `STOCKFISH_NETWORK_DIR="$PWD/third_party/networks"`. Gradle-зависимости загружаются из Google Maven и Maven Central.

Gradle создаёт подписанный отладочный APK в `app/build/outputs/apk/debug/` и неподписанный релизный APK в `app/build/outputs/apk/release/`. Для распространения собственной сборки подпишите её своим ключом с помощью `apksigner`. Обновление установленного APK требует того же ключа.
