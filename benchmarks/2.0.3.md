# ChessMind 2.0.3 — браузер и серверный стенд

## Сравнение анализа

Один прогон на конфигурацию. Linux, Intel Xeon Platinum 8573C, три доступных логических CPU, Node.js 24.22.3, Chromium 156. Stockfish 19 WASM Lite, один поток и Hash 16 МиБ. Браузер использовал production-сборку, Node.js — HTTP через loopback и новый Worker на запрос. Архивные ответы для исторических партий воспроизводились на стенде. Первый байт HTTP на стенде приходил за 12–113 мс, инициализация нового Stockfish Worker занимала 305–653 мс. RSS процесса Node.js в конце запроса составлял 128–143 МиБ. Пиковый суммарный PSS всех процессов Chromium составлял 337–449 МиБ. RSS и PSS учитывают память по-разному. Холодный старт Vercel, сетевые задержки в production и физические смартфоны не измерялись.

В Express для Оперной партии совпали Accuracy 99,35% / 79,99%, ACPL 5,53 / 74,27 и все глубины. Для Бессмертной браузер показал 69,00% / 61,36%, ACPL 43,05 / 51,26, стенд — 71,79% / 62,80%, ACPL 41,50 / 48,58. На этой партии поиск выполнил 3,40 и 3,64 млн узлов соответственно. По одному прогону с лимитами поиска и разными планировщиками нельзя оценить систематическое изменение качества. В четырёх полуходах каждого теста Standard совпали глубины и показатели Accuracy, ACPL не вычисляется для этих матовых оценок. Оба источника используют общую методологию, включая WDL и классификацию.

### Выбор серверной сборки

Отдельный UCI-прогон восьми позиций Оперной партии. Один поток, Hash 16 МиБ, MultiPV 2, пределы depth 16 и 400 тыс. узлов на позицию.

| Stockfish 19 | Запуск, с | Поиск, с | Узлов/с | Пиковый RSS, МиБ |
|---|---:|---:|---:|---:|
| Нативный Linux x86-64 | 1,46 | 4,10 | 631 тыс. | 316 |
| WASM Full | 2,79 | 10,27 | 252 тыс. | 474 |
| WASM Lite | 0,22 | 5,80 | 463 тыс. | 125 |

Для сервера выбран WASM Lite из-за быстрого запуска, меньшего расхода памяти и возможности измерить CPU изолированного Node.js Worker. Нативная сборка быстрее в этом поисковом тесте. Её совместимость с production Vercel не проверялась.

## Квота и проверки

Vercel Hobby включает 4 часа Active CPU, 360 ГБ·ч выделенной памяти и 1 млн вызовов в месяц. Active CPU учитывает работу процессора отдельно от ожидания HTTP и учёта выделенной памяти. Для Node.js с Fluid Compute на Hobby доступны 2 ГБ, 1 vCPU и до 300 секунд. Обычная сборка функции ограничена 250 МБ без сжатия, запрос и ответ без потоковой передачи — 4,5 МБ. [Hobby](https://vercel.com/docs/plans/hobby) · [Usage and Pricing](https://vercel.com/docs/functions/usage-and-pricing) · [Function Limits](https://vercel.com/docs/functions/limitations) · [Fluid Compute](https://vercel.com/docs/fluid-compute) · [Streaming](https://vercel.com/docs/functions/streaming-functions)

Счётчики WAF действуют по регионам. Spend Management доступен на Pro и Enterprise. У существующей инфраструктуры нет общего атомарного допуска к вычислениям, который гарантирует жёсткую месячную квоту ChessMind. В production статус отдаётся статически, а вычислительный маршрут закрыт на уровне маршрутизации Vercel. Публично доступно 0 облачных запусков. [Rate Limiting](https://vercel.com/docs/vercel-firewall/vercel-waf/rate-limiting) · [Spend Management](https://vercel.com/docs/spend-management)

Прототип требует атомарного резерва 30 секунд CPU на попытку, максимум 1 час в месяц и один запрос одновременно. Это даёт максимум 120 допущенных попыток, включая отменённые и неудачные. Лимиты работы — 20 секунд измеряемого CPU и 25 секунд общего времени. Express принимает до 100 полуходов, Standard до 40. Максимумы данных — 1 КиБ JSON и 48 КиБ архивного PGN. Запросы без доказательства завершения из официального архива, повторы и параллельные запросы отклоняются на стенде. При отмене Worker завершается, зарезервированный бюджет сохраняется. Аварийный переключатель обработчика — `CHESSMIND_CLOUD_ENABLED`.

Воспроизведение после `npm run build` и запуска `npm run preview -- --port 4203`:

```sh
node --import tsx scripts/benchmark-cloud.ts
BENCH_MODES=quick node --import tsx scripts/benchmark.mjs http://localhost:4203 express.ndjson
BENCH_TAIL=4 BENCH_MODES=standard,deep,professional node --import tsx scripts/benchmark.mjs http://localhost:4203 endings.ndjson
```
